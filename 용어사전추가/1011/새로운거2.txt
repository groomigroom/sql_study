문제 16

4지선다
급여 값이 모두 서로 다른 EMP 테이블에서 급여가 가장 적은 직원 5명을 조회하려고 한다. 다음 중 실행 순서 때문에 의도와 다른 결과를 낼 수 있는 SQL은?

SQL
-- (가) SQL Server
SELECT TOP 5 * FROM EMP ORDER BY SAL ASC;

-- (나) SQL Server
SELECT TOP 5 WITH TIES * FROM EMP ORDER BY SAL ASC;

-- (다) Oracle
SELECT * FROM EMP WHERE ROWNUM <= 5 ORDER BY SAL ASC;

-- (라) 표준 SQL
SELECT * FROM EMP ORDER BY SAL ASC FETCH FIRST 5 ROWS ONLY;
1.
(가)

2.
(나)

3.
(다)

4.
(라)

정답

3번

(다)

해설

정답은 ③ (다)이다. Oracle의 같은 쿼리 블록에서 ROWNUM <= 5는 ORDER BY 정렬보다 먼저 적용된다. 따라서 임의로 선택된 5행만 급여순으로 정렬될 뿐, 전체 EMP에서 급여가 가장 적은 5행이 보장되지 않는다. ① TOP 5와 ④ FETCH FIRST 5 ROWS ONLY는 ORDER BY가 지정한 순서의 앞 5행을 제한한다. ② WITH TIES는 경계값과 같은 행을 추가로 포함하지만, 문제에서 급여가 모두 서로 다르다고 했으므로 정확히 5행이 반환된다. (다)를 고치려면 ORDER BY를 인라인 뷰 안에서 먼저 수행하고 바깥 쿼리에서 ROWNUM을 적용해야 한다.
