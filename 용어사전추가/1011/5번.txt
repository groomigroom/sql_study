문제 20

4지선다
다음 테이블 T에 한 행을 입력하려고 한다. 제약조건을 위반하지 않고 NULL을 입력할 수 있는 것은?

SQL
CREATE TABLE T (
    가 CHAR(3),
    나 VARCHAR2(10) NOT NULL,
    다 VARCHAR2(10) UNIQUE,
    라 VARCHAR2(10) CHECK (라 IS NOT NULL),
    PRIMARY KEY (가)
);
1.
(NULL, 'b', 'c', 'd')

2.
('a', NULL, 'c', 'd')

3.
('a', 'b', NULL, 'd')

4.
('a', 'b', 'c', NULL)

정답

3번

('a', 'b', NULL, 'd')

해설

정답은 ③ 다 열에 NULL을 넣는 행이다. UNIQUE 제약조건은 중복된 비NULL 값을 금지하지만 일반적으로 열 자체에 NULL 입력을 금지하지 않는다. ①의 가는 PRIMARY KEY이므로 고유성과 NOT NULL 특성을 모두 가져 NULL을 허용하지 않는다. ②의 나에는 명시적인 NOT NULL 제약조건이 있어 위반된다. ④의 라는 CHECK 조건이 라 IS NOT NULL이므로 NULL을 넣으면 조건이 FALSE가 되어 입력할 수 없다. 따라서 네 행 중 모든 제약을 통과하면서 NULL을 포함하는 것은 ③뿐이다. 보충: NULL을 금지하려면 UNIQUE만으로는 부족하며 NOT NULL을 별도로 지정해야 한다.
