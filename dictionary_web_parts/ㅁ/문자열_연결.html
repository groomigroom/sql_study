sql에서 문자열 결합 연산자는 concat 함수와 같은 기능인가
        문자열을 합치는 기능은 같지만, 
        NULL 처리 방식과 인자 개수 제한 등 세부 동작에서 차이가 있습니다. 
        사용하는 데이터베이스(DBMS) 종류에 따라 
        연산자(||, +)와 CONCAT 함수의 지원 여부도 다릅니다.
        주요 차이점
        NULL 값 처리
        CONCAT 함수: NULL을 빈 문자열('')로 취급하여 무시하고 나머지 문자열을 이어줍니다.
        연산자(+ 등): 피연산자 중 하나라도 NULL이면 결과 전체가 NULL이 됩니다 (단, 오라클의 || 등은 예외적으로 빈 문자열 취급을 하기도 함).
        인자(입력값) 개수
        CONCAT 함수: MySQL 등은 3개 이상의 문자열을 한 번에 넣을 수 있지만, 
        오라클(Oracle)의 CONCAT은 인자를 딱 2개만 받습니다.
        자동 형변환
        CONCAT 함수: 숫자 등 다른 데이터 형식을 넣어도 자동으로 문자로 
        바꿔서 안전하게 결합합니다.
        연산자(+ 등): SQL Server(MSSQL)의 + 연산자는 데이터 타입이 다르면 
        직접 형변환(CAST 등)을 해야 오류를 막을 수 있습니다.
        DBMS별 지원 현황
        MySQL: CONCAT(str1, str2) 함수와 CONCAT_WS 등을 주로 씁니다.
        Oracle: 연결 연산자 ||를 주로 쓰며, CONCAT(str1, str2) 
        함수도 지원하나 2개만 연결 가능합니다.
        SQL Server (MSSQL): 더하기 연산자 +와 CONCAT 함수를 모두 지원합니다.
