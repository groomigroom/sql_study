SQL에서 Grouping(그룹화)은 크게 두 가지 맥락으로 나뉩니다. 첫째는 데이터를 같은 값끼리 묶는 GROUP BY 절의 개념이고, 둘째는 소계·총계 행을 식별하는 GROUPING() 내장 함수입니다. [1] 
------------------------------
## 1. 데이터 그룹화의 개념 (GROUP BY)
데이터베이스에서 동일한 값을 가진 행들을 하나의 요약된 행으로 합치는 과정을 뜻합니다. 주로 데이터 통계를 내거나 리포트를 작성할 때 사용합니다. [2] 

* 
* 핵심 특징: 그룹화를 하면 기존 레코드의 상세 정보는 사라지고, 그룹당 단 하나의 행만 남게 됩니다.
* 함께 쓰는 집계 함수: 집계 함수(SUM, AVG, COUNT, MAX, MIN)를 사용하여 그룹별 합계나 평균 등을 계산합니다. [2, 3, 4, 5] 
* 

-- 부서별로 급여 평균을 구하는 그룹화 예시SELECT 부서ID, AVG(급여) FROM 임직원 GROUP BY 부서ID;

------------------------------
## 2. SQL 내장 함수로서의 의미 (GROUPING())
GROUP BY 절에 ROLLUP, CUBE, GROUPING SETS 같은 확장 함수를 쓰면 그룹별 소계(Subtotal)와 총계(Total) 행이 결과에 추가됩니다. 이때 어떤 행이 실제 데이터이고 어떤 행이 소계·총계인지 판별해 주는 함수가 바로 GROUPING() 함수입니다. [1, 6, 7, 8] 

* 
* 반환 값:
* 0: 일반적인 그룹화 데이터 행입니다.
   * 1: ROLLUP이나 CUBE에 의해 생성된 소계 또는 총계 행입니다 (해당 컬럼의 데이터가 집계 대상에 포함되어 비어있음을 의미). [1, 8] 
* 

## 💡 실제 활용 예시
소계나 총계가 계산된 자리에 NULL 대신 '소계' 또는 '총계'라는 명확한 글자를 표시하고 싶을 때 [Microsoft Learn의 GROUPING 가이드]
(https://learn.microsoft.com/ko-kr/sql/t-sql/functions/grouping-transact-sql?view=sql-server-ver17)에 따라 CASE문이나 DECODE와 조합하여 자주 사용합니다. [9, 10] 

SELECT 
    CASE WHEN GROUPING(부서ID) = 1 THEN '모든부서 합계' ELSE 부서ID END AS 부서,
    SUM(급여) AS 급여합계FROM 임직원GROUP BY ROLLUP(부서ID);
