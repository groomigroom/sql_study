SQL에서 시퀀스(Sequence)란 유일하고 순차적인 정수 값을 자동으로 생성하는 독립적인 데이터베이스 객체입니다.

[2] (https://translate.google.com/translate?u=https://www.quora.com/What-is-a-sequence-in-MySQL-or-any-other-DBMS-How-do-you-use-it-to-generate-a-primary-key&hl=ko&sl=en&tl=ko&client=sge), 
[3] (https://www.youtube.com/watch?v=MRWpNnM9ot0)

주요 특징

• 중복 방지 및 자동 번호 생성: 주로 테이블의 기본키(Primary Key, PK) 값에 중복 없이 순서대로 번호를 부여할 때 사용합니다. 
[1] (https://velog.io/@floyd/SQL-SEQUENCE-%EB%9E%80), 
[2] (https://jinnnkcoding.tistory.com/79),
[3] (https://jju240.tistory.com/94)
• 독립성: 특정 테이블에 속하지 않고 데이터베이스 내에 독립적으로 존재하므로, 여러 테이블에서 공유하여 사용할 수 있습니다. 
[1] (https://m.blog.naver.com/dnjswls23/222311759854), 
[2] (https://www.youtube.com/watch?v=MRWpNnM9ot0)
• 주요 설정 옵션:
	• START WITH: 시작 값 지정
	• INCREMENT BY: 증가하는 값(증감치) 지정
	• MAXVALUE / MINVALUE: 최댓값 및 최솟값 지정
	• CYCLE / NOCYCLE: 최댓값 도달 후 다시 처음부터 반복할지 여부 결정
	• CACHE / NOCACHE: 메모리에 시퀀스 값을 미리 할당해 속도를 높일지 여부 결정 
[1] (https://do-develop-diary.tistory.com/3), 
[2] (https://m.blog.naver.com/dnjswls23/222311759854), [3] (https://www.youtube.com/watch?v=MRWpNnM9ot0)

주요 함수

• NEXTVAL (Next Value): 시퀀스의 다음(다음 순번) 값을 생성하고 반환합니다. 호출할 때마다 값이 증가합니다.
• CURRVAL (Current Value): 현재 세션에서 가장 최근에 생성된 시퀀스 값을 확인합니다. 
[1] (https://m.blog.naver.com/dnjswls23/222311759854), [2] (https://do-develop-diary.tistory.com/3)

사용 예시 (오라클/PostgreSQL 등 기준)

1. 시퀀스 생성하기sql
CREATE SEQUENCE customer_id_seq
START WITH 1
INCREMENT BY 1
MAXVALUE 1000
NOCYCLE;
코드를 사용할 때는 주의가 필요합니다.
2. 다음 값 가져오기sql
SELECT customer_id_seq.NEXTVAL FROM DUAL;
코드를 사용할 때는 주의가 필요합니다.
3. 테이블에 데이터 삽입 시 활용하기sql
INSERT INTO customer_tbl (id, name)
VALUES (customer_id_seq.NEXTVAL, '홍길동');
코드를 사용할 때는 주의가 필요합니다.
