MySQL에서 특정 테이블을 생성할 때 사용한 SQL 구문(CREATE TABLE)을 확인하려면 아래 명령어를 사용합니다. [1] (https://itholic.github.io/database-mysql-show-create-table/), [2] (https://gocoder.tistory.com/2379)

기본 문법

sql
SHOW CREATE TABLE 테이블명;
코드를 사용할 때는 주의가 필요합니다.
• 예시 (users 테이블 확인 시): [1] (https://hxnsxxm.tistory.com/33)
sql
SHOW CREATE TABLE users;
코드를 사용할 때는 주의가 필요합니다.

대소문자 및 줄바꿈 정리해서 보기

기본 명령어로 조회하면 긴 구문이 한 줄로 출력되어 보기 불편할 수 있습니다. 줄바꿈을 적용해 가독성을 높이려면 뒤에 \G를 붙여 실행합니다.
sql
SHOW CREATE TABLE users\G
코드를 사용할 때는 주의가 필요합니다.
(세미콜론 ; 대신 \G를 입력하면 세로 형태의 정돈된 레이아웃으로 출력됩니다.)

기타 테이블 구조 확인 명령어

• 컬럼 목록과 데이터 타입만 간단히 확인:sql
DESCRIBE 테이블명;
-- 또는
DESC 테이블명;
코드를 사용할 때는 주의가 필요합니다.
